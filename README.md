## 1. 개발 의도

중학생의 하루에는 확인할 것이 많습니다. 시간표, 학교 행사, 급식 메뉴와 알레르기, 준비물, 용돈까지 서로 다른 곳에 흩어져 있어 불편했습니다. 그래서 "언제, 어디서 쓰는 정보인가"를 기준으로 한곳에 모은 앱을 만들었습니다.

## 2. 적용 대상

- 사용 대상: 중학생(검색으로 전국 어느 학교든 선택할 수 있음), 알레르기가 있는 학생
- 사용 상황: 아침 등교 전, 수업 중, 점심시간, 하교 후, 쉬는 시간

## 3. 주요 기능과 사용 방법

**분류 기준: 언제, 어디서 쓰는가**

| 카테고리 | 분류 기준 | 들어 있는 기능 |
| --- | --- | --- |
| 🎒 등교 | 집에서 나서기 전에 확인하는 것 | 등교까지 남은 시간, 오늘 챙길 과목, 체육복 알림, 가까운 D-day, 등교 준비물 체크리스트 |
| 📚 학교 | 학교에서 수업을 들을 때 확인하는 것 | 이번 주 시간표(과목별 색상, 지금 수업 강조), 학사 일정, 내 D-day(시험·수행평가를 직접 등록), 숙제 노트(마감일 알림) |
| 🍱 급식 | 점심시간에 먹는 급식에 관한 것 | 급식 예보 점수, 알레르기 경고, 주간·월간 급식, 급식 일기와 취향 |
| 🏡 하교 | 학교를 마친 뒤에 확인하는 것 | 하교까지 남은 시간, 내일 시간표·급식 미리보기, 하교 후 할 일 |
| ✨ 생활 | 시간과 상관없이 언제든 쓰는 것 | 용돈 기입장(수입·지출·분류별 통계·저축 목표), 공부 타이머(집중 시간과 최근 7일 통계), 설정(글자 크기, 고대비 모드, 기록 백업·복원), 미니게임(카드 짝 맞추기, 구구단 스피드 퀴즈) |

- 지금 시각에 맞는 카테고리가 앱을 열 때 자동으로 열립니다. (예: 점심시간에는 급식)
- **급식 예보**: 메뉴에 내 취향 점수를 매겨 ☀️⛅☁️🌧로 보여 줍니다. 메뉴를 눌러 ♥ 좋아요 / ✕ 싫어요를 남기면 점수가 나에게 맞춰지고, 별점을 남기면 다음 예보에 자동으로 반영됩니다.

**사용 방법**

1. 앱 주소에 접속해서 학교 이름을 검색하고 선택합니다.
2. 학교 카테고리의 시간표에서 학년과 반, 등교 시각, 수업 시간을 설정합니다.
3. 아래쪽 메뉴에서 지금 필요한 카테고리를 고릅니다.

## 4. 기대 효과

- 글자 크기와 고대비 모드를 지원해 시력이나 읽기 편의가 서로 다른 학생도 쓸 수 있습니다(모두를 위한 앱).
- 등교 전부터 하교 후까지 필요한 정보를 한 앱에서 확인할 수 있어 준비물을 빠뜨리는 일이 줄어듭니다.
- 알레르기가 있는 학생이 급식을 더 안전하게 먹을 수 있습니다.
- 용돈 기입장으로 소비 습관을 돌아보게 됩니다.
- 서버 없이 기기 안에 기록을 저장해 개인정보를 수집하지 않습니다.

- **처음에 AI에게 한 요청(프롬프트)**:

  - 이후 날씨 등을 빼고 "급식 하나로" 집중하자고 방향을 정했습니다.
  - 인증키는 직접 발급받아 코드에 넣었습니다.
  - (여기에 직접 고친 부분을 더 적어 주세요.)

## 사용한 공공데이터와 한계

- **공공데이터**: 교육부 나이스(NEIS) 교육정보 개방 포털의 급식식단정보, 학사일정, 시간표, 학교정보 (https://open.neis.go.kr)
- 급식 예보 점수는 "내가 좋아하는 메뉴가 얼마나 있는가"만으로 계산한 단순한 값이며, 영양이나 맛을 평가하는 점수는 아닙니다.
- 알레르기 정보는 참고용입니다. 정확한 내용은 학교 급식실에서 꼭 확인하세요.
- 하교 시각은 학교가 공개한 데이터가 없어서, 시간표의 마지막 교시와 내가 설정한 수업 시간으로 계산한 예상값입니다.
- 취향, 일기, 체크리스트, 용돈 기록은 사용하는 기기의 브라우저에만 저장됩니다.
